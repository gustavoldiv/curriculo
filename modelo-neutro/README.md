# Modelo neutro de portfólio

Abra index.html para visualizar a estrutura. Preencha js/config.js com os dados do novo profissional. Configure identidade, foto local, contatos, trajetória, formação, competências e cases. A configuração começa sem informações pessoais.

A página não precisa de build, Node ou backend. Para testar por HTTP, execute `python -m http.server 8000` e abra http://localhost:8000. O formulário usa mailto e não envia sozinho.

Revise as frases genéricas de sistemas e negócios em index.html, os metadados do head e a paleta CSS para cada cliente. Configure GitHub e sua lista local somente com repositórios públicos revisados. Fotos, marcas e conteúdo de clientes precisam de autorização própria.

Publique o conteúdo desta pasta na raiz de uma branch do repositório e selecione Settings → Pages → Deploy from a branch → branch aprovada → /(root). Faça backup e teste em branch separada antes de substituir uma página existente.
